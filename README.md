# Diwali Sales Analysis

## Project Overview
This project analyzes Diwali sales data to understand customer
purchasing behavior and sales performance.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning
- Exploratory Data Analysis
- Customer analysis by gender
- Age-group analysis
- Occupation analysis
- Product category analysis

## Key Insights
- Identified customer purchasing patterns
- Analyzed top-performing product categories
- Studied sales trends across different customer groups

## Project Files
- Diwali_Sales_Analysis.ipynb – Complete analysis
- Diwali_Sales_Data.csv – Dataset
